## Acute Lymphocytic Leukemia (ALL) Cell Detection using YOLOv5

## Overview
This project applies the YOLOv5 object detection model to identify Acute Lymphocytic Leukemia (ALL) cells in microscopic bone marrow images. It was developed as part of our undergraduate thesis research.

## Highlights
Trained a custom YOLOv5 model for ALL cell detection.
Performed image preprocessing using OpenCV.
Trained on a custom annotated microscopy dataset.
Published in the 2025 9th International Conference on Electrical, Electronics and Information Engineering (ICEEIE).
Awarded Best Presenter during the research conference.

## Technologies
Python
YOLOv5
PyTorch
OpenCV

## Dataset
The dataset used in this research was obtained through a local medical institution. Due to privacy and institutional restrictions, it cannot be publicly shared.
